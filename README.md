## โครงสร้างโปรเจกต์
- `docs/uml/` : เก็บไฟล์ออกแบบ Use Case Diagram และ Class Diagram (.drawio, .png)
- `src/routes/` : จัดการเส้นทาง API Endpoint
- `src/controllers/` : จัดการ Logic การทำงานของระบบ
- `src/models/` : จัดการโครงสร้างข้อมูลและฐานข้อมูล
- `src/config/` : ไฟล์ตั้งค่าระบบและการเชื่อมต่อฐานข้อมูล
